# Coarse evaluation: healthy / rust / septoria

Generated by `python -m zarai.vision.coarse_eval` from configs/vision/coarse_eval.yaml, from the saved predictions of experiments/vlm_zero_shot.md (Gemma answers, DINOv2-B logits). Nothing is run or fit. All numbers are measured.

**Coarse classes.** *healthy* = healthy; *rust* = yellow_rust, brown_rust, black_rust; *septoria* = septoria. A rust called the wrong rust counts as correct.

**Methods.** *DINOv2-B alone*: its fine argmax mapped to the coarse class, mean over 3 seeds (pooled run for pooled test and NWRD, each LOSO fold's run for its held-out source). *Gemma alone*: its answer mapped to the coarse class; unsure and invalid answers are not answered. *Agree-rule*: answers when DINOv2-B and Gemma give the same coarse class, otherwise defers (Gemma unsure or invalid also defers); mean over DINOv2-B's 3 seeds.

**Columns.** *coverage* = share answered. *accuracy* = on answered images. *macro-F1* averages the coarse classes present, with unanswered images scored as wrong (not given for the agree-rule, which defers by design). *recall* = correct / all images of that class, so deferred and unsure count as missed. In-context variants leave out their 5 reference images.
