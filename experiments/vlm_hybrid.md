# Hybrid of DINOv2-B and Gemma 4

Generated by `python -m zarai.vision.vlm_hybrid` from configs/vision/vlm_hybrid.yaml, using the Gemma answers of experiments/vlm_zero_shot.md and the logits the DINOv2-B runs logged. All numbers are measured; DINOv2-B rows and every hybrid are means over its 3 seeds.

**Methods.**

- *DINOv2-B alone*: argmax, answers every image.
- *Gemma alone*: answers unless it says unsure or the answer is invalid.
- *(a) rule*: answers DINOv2-B's class when Gemma gives the same class; otherwise (different class, unsure or invalid) it defers, i.e. would ask a clarifying question.
- *(b) stacker*: multinomial logistic regression (C = 1.0, not tuned) on DINOv2-B's temperature-calibrated probabilities (5), Gemma's answer one-hot (5 classes, unsure, invalid) and Gemma's stated confidence. Answers every image.
- *(b) stacker, deferring* and *DINOv2-B, deferring*: answer only when their top probability is above a threshold. The threshold is set on the val split so that they answer as often there as rule (a) does with the same Gemma variant (the stacker's val probabilities for this are out-of-fold, 5-fold). On the test set their coverage can differ from the rule's.

**What is fit where.** Nothing is fit on a test set. For a held-out source the DINOv2-B run is that LOSO fold's, and its temperature, the stacker and the thresholds are fit on that run's validation split, which contains only the other sources. Pooled test and NWRD use the pooled run and its validation split (NWRD is never in it; the pooled split's val and test hold the same sources). Gemma itself is not trained. Caveat carried over from the zero-shot report: in-context references are drawn from the pooled train split, and 4 of the 5 come from kaggle and 1 from cgiar_wheat_rust, so for those two held-out sources the in-context variant has seen one or more photos from the held-out source in its prompt. References are left out of every val and test set here.

**Columns.** *coverage* = share of images answered. *accuracy* = on answered images. Recall *answered* = correct / answered images of that class; *all* = correct / all images of that class (deferred counts as not found).
